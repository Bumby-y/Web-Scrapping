# Shared documentation

Put documentation that applies across multiple modules here, such as
contribution guidance, shared conventions, and repository-wide design notes.
Module-specific setup and API documentation belongs with each module.

Use this folder for repository-wide guidance on versioning, distribution,
permissions, and compatibility across AI orchestrators.

- [`ARCHITECTURE.md`](./ARCHITECTURE.md) describes module boundaries,
  replaceable adapters, and storage-independence goals.
