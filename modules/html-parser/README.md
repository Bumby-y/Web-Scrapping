# HTML Parser

An independently packaged Python module for turning HTML documents into
structured information that downstream scraping workflows can use.

This is currently a scaffold; parsing behavior and supported input formats
have not been implemented. Document the public interface and parsing behavior
here as they are developed.

The `module.json` file provides machine-readable discovery metadata.
The module-local skill under `skills/html-parser/SKILL.md` provides AI-agent
usage guidance and should be updated alongside the public package interface.
