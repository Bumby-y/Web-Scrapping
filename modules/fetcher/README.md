# Fetcher

An independently packaged Python module for retrieving web resources over
HTTP. It is intended for reusable request and response-handling functionality
that other scraping workflows can build on.

This is currently a scaffold; fetching behavior has not been implemented.
Describe supported options, errors, and network behavior here as the public
interface is developed. Review the target site's terms and access policies
before making requests.

The `module.json` file provides machine-readable discovery metadata.
The module-local skill under `skills/fetcher/SKILL.md` provides AI-agent usage
guidance and should be updated alongside the public package interface.
